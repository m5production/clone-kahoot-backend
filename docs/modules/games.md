# Модуль games

## Назначение

Квизы пользователя (наборы вопросов).

## Данные и правила

`Game`: `id`, `adminId` → `User` cascade, `createdAt`. Владелец — только из сессии.

## Интерфейсы

- `GET /api/games` — список своих игр.
- `POST /api/games` — создать игру (владелец = текущий пользователь).
- `GET /api/games/:id`, `DELETE /api/games/:id` — только владелец (404 чужая).

## Зависимости

`PrismaService`, `AuthGuard`.

## Транзакции

Удаление игры каскадно удаляет вопросы и ответы (FK cascade).

## Тесты

E2e: создание через UI, список только своих игр (чужая не видна).
