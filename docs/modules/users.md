# Модуль users

## Назначение

Публичные профили и управление своим аккаунтом.

## Данные и правила

`User`: `id`, `name` (unique), `passwordHash`. Публичная форма — только `{id, name}`.

## Интерфейсы

- `GET /api/users/:id` — публичный профиль (сессию не создаёт).
- `PUT /api/users/:id` — смена имени (только себя; валидация 409/403).
- `DELETE /api/users/:id` — удаление аккаунта (только себя; каскад игр/сессий).

## Зависимости

`PrismaService`; `AuthGuard` для изменяющих операций.

## Доступ

Любое изменение `users/:id` требует `session.userId === :id` — иначе 403.

## Тесты

E2e: отображение имени, уникальность, список только своих ресурсов.
